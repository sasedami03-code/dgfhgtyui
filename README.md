# Эмуляция синтетической теории эволюции для поиска «максимально умной» сети

## 1) Формализация
Пусть особь — это тройка
\[
\mathcal{I}=(\theta,\,\psi,\,\mathfrak{a}),
\]
где:
- \(\theta\in\mathbb{R}^{n(\mathfrak{a})}\) — непрерывный генетический код (параметры модели),
- \(\psi=(\sigma,\lambda,s,\eta,h)\) — мета-гены: дисперсия мутации, репродуктивность, число локальных шагов обучения, скорость локального поиска, ширина,
- \(\mathfrak{a}\in\{\text{MLP},\text{POLY},\text{FOURIER},\text{RBF},\text{GATED}\}\) — архитектурный ген.

Популяция в поколении \(t\):
\[
\mathcal{P}_t=\{\mathcal{I}_{t,1},\dots,\mathcal{I}_{t,N_t}\},\quad N_t\in[12,80],
\]
где \(N_t\) не фиксирован и определяется самими особями через \(\lambda\).

## 2) Многомодальная целевая функция
Данные объединяются из разных источников:
- численная регрессия: \((x_n,y_n)\sim D_{num}\),
- временной ряд: \((x_t,y_t)\sim D_{ts}\),
- текст: \((c_i,c_{i+1})\sim D_{txt}\).

Фитнес (максимизируется):
\[
F(\mathcal{I})=-\Big(0.5\,\mathrm{MSE}_{num}+0.3\,\mathrm{MSE}_{ts}+0.2\,\mathrm{CE}_{txt}+10^{-4}\lVert\theta\rVert_2^2\Big).
\]

## 3) Мутация, кроссовер, локальное обучение
Самоадаптивная мутация:
\[
\sigma' = \mathrm{clip}(\sigma\,e^{\tau\xi},10^{-3},1.2),\quad
\theta' = \theta + \sigma'\varepsilon,
\]
\[
\varepsilon\sim\mathcal{N}(0,I),\;\xi\sim\mathcal{N}(0,1).
\]

Кроссовер параметров:
\[
\theta^{child}_i = \theta^{(1)}_{i\bmod n_1}\;\text{или}\;\theta^{(2)}_{i\bmod n_2}.
\]

Локальное обучение (поиск пробой):
\[
\theta \leftarrow \arg\max_{\theta+\Delta,\;\Delta\sim\mathcal{N}(0,\eta^2I)} F(\theta+\Delta)
\]
в течение \(s\) шагов.

## 4) Модели (без ограничения одной формой)
Семейство гипотез — объединение пяти классов:
\[
\mathcal{H}=\mathcal{H}_{MLP}\cup\mathcal{H}_{POLY}\cup\mathcal{H}_{FOURIER}\cup\mathcal{H}_{RBF}\cup\mathcal{H}_{GATED}.
\]

Примеры:
- MLP: \(f(x)=W_2\,\phi(W_1x+b_1)+b_2\),
- POLY: \(f(x)=z_1+z_2^2+z_3^3,\;z=Ax+c\),
- FOURIER: \(f(x)=W_2\sin(\Omega x+\varphi)+b_2\),
- RBF: \(f(x)=W_2\exp(- (\Omega x+\varphi)^2 )+b_2\),
- GATED: \(f(x)=W_2(\sigma(W_gx+b_g)\odot\phi(W_mx+b_m))+b_2\).

## 5) Эволюционный цикл
\[
\mathcal{P}_{t+1}=\mathrm{SelectElite}(\mathcal{P}_t)\cup
\mathrm{Mutate/Crossover}(\mathrm{Elite}_t),
\]
\[
N_{t+1}=\mathrm{clip}\left(\sum_{e\in\mathrm{Elite}_t}\lambda_e,12,80\right).
\]

## 6) Мини-теоремы (в рамках эмуляции)
1. **Невырожденность поиска**: если \(\sigma>0\), то мутационное ядро имеет полную поддержку в \(\mathbb{R}^{n}\), следовательно достижимы любые открытые области параметрического пространства за конечное число поколений с ненулевой вероятностью.
2. **Монотонность элитизма**: при копировании лучшей особи в новое поколение \(\max F(\mathcal{P}_{t+1})\ge\max F(\mathcal{P}_t)\).
3. **Богатство класса**: \(\mathcal{H}\) содержит полиномиальные, тригонометрические и радиально-базисные аппроксиматоры, что расширяет покрытие функций по сравнению с одним фиксированным анзацем.

## 7) Запуск
```bash
python evolution_emulator.py
```
Скрипт бесконечный: работает, пока вы не остановите (`Ctrl+C`). На каждом поколении печатается формула лучшей особи.
